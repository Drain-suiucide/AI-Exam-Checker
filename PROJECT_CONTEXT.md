AI Exam Checker
Назначение
Исследовательский веб-прототип проверки развёрнутых ответов ЕГЭ по истории (позже по всем предметам, включая ОГЭ)

Система помогает продемонстрировать возможность:

загрузки ответа;
OCR распознавания;
проверки по утверждённым критериям;
получения объяснимой оценки.
Целевая аудитория
жюри конкурса;
эксперты по образованию;
исследователи EdTech;
разработчики системы.
Демонстрационный сценарий
Пользователь:

Загружает скан ответа или вводит ответ вручную.
Проверяет результат OCR.
Запускает проверку.
Получает оценку.
Получает объяснение по критериям.
Видит спорные места и уверенность модели.
Границы MVP
В MVP:

только один предмет;
только история;
только одно задание;
только одна официально подтверждённая версия критериев.
Что НЕ входит в MVP
Не входит:

автоматическое выставление государственных баллов;
поддержка всех предметов;
проверка всей работы ЕГЭ;
экспертная модерация в реальном времени;
личные кабинеты;
платёжные функции.
Предмет MVP
История.

Точное задание должно быть выбрано и подтверждено по официальным материалам ФИПИ.

До завершения исследования номер задания считается неутверждённым.

Безопасность
Запрещено хранить реальные персональные данные обучающихся.

Для тестов используются только:

синтетические ответы;
обезличенные примеры.
Предварительный стек
Frontend:

React
TypeScript
Backend:

Python

PostgreSQL

Стек считается предварительным до ADR-решения.

Правила работы агентов
Каждая задача:

имеет одного владельца;
имеет один результат;
редактирует только разрешённые файлы.
Изменение API или модели данных требует согласования.

Термины
OCR — распознавание текста.

Criterion — критерий оценивания.

Evaluation — процесс проверки ответа.

Evidence — фрагмент ответа, подтверждающий оценку.

Confidence — уверенность модели.
