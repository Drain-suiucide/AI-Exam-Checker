# Acceptance Criteria

## MVP считается готовым если

### OCR

- загружается изображение;
- текст распознаётся;
- пользователь может исправить ошибки.

### Evaluation

- используется подтверждённое задание;
- используются подтверждённые критерии;
- по каждому критерию выводится обоснование.

### Explainability

- показываются фрагменты ответа;
- показывается уверенность модели.

### Demo

- сценарий проходит от начала до конца.
