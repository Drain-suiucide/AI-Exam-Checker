## 5. Оставшиеся действия перед публикацией

1. **[БЛОКЕР] Лицензия.** Владелец выбирает лицензию (рекомендация: MIT). Добавить `LICENSE` в корень, обновить раздел «Лицензия» в README.md и CONTRIBUTING.md.
2. **Чистая проверка запуска.** На машине без локальных настроек: clone → `docker compose up --build -d` → health-check → демо-сценарий → `uv run pytest` / `npm test`.
3. **Известные дефекты (не блокируют публикацию исходников, но должны быть видны):** DEF-001 (нет RBAC), DEF-002 (нет rate limiting), DEF-003 (npm audit: 2 критические уязвимости в dev-зависимостях), DEF-004 (ruff-замечания), DEF-005 (маршруты submissions не зарегистрированы в HTTP). Все перечислены в README и qa-report.md.
4. **Решение владельца о публикации:** перевод репозитория в public, включение Security Advisories, настройка описания и топиков репозитория — только по явному разрешению.

## 6. После публикации
