# Методология оценивания (Задача 9)

## 1. Версионирование критериев
Каждый набор критериев привязан к конкретному экзамену (например, ЕГЭ по истории), году и идентификатору задания. Критерии неизменяемы.

## 2. Разделение инструкций
- **Официальная формулировка:** Точная копия текста ФИПИ.
- **Инструкция для LLM:** Детализированное руководство для модели без искажения официального смысла.

## 3. Обработка неопределенности
Модель не принимает окончательное решение в сомнительных ситуациях. Ответ направляется на ручную проверку, если:
- Нет доказательного фрагмента в тексте.
- Противоречивый ответ.
- Подозрение на промпт-инъекцию в ответе ученика.

## 4. Использование LLM
Ответ ученика оборачивается в защищенный блок и маркируется как недоверенный. Модель возвращает результат строго в JSON-формате по схеме Pydantic, после чего бэкенд валидирует баллы.
