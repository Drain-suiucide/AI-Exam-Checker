# Описание тестового набора

Все данные в репозитории — **синтетические**. Реальных экзаменационных работ, персональных данных и материалов без разрешения в наборе нет. Формулировки ответов вымышленные; исторические факты — из школьной программы.

## 1. Набор для оценки OCR

**Расположение:** `backend/tests/ocr/fixtures/synthetic/`

**Состав:** 34 изображения, отрисованные кодом репозитория (`backend/app/services/ocr/dataset.py`) системными шрифтами Windows с кириллицей. Эталонные тексты и разметка критичных сущностей — в `manifest.json`.

| Категория | Описание | dev | test |
|---|---|---|---|
| `printed` | Чистый печатный текст, белый фон | 5 | 2 |
| `low_light` | Низкий контраст, тусклое освещение | 3 | 1 |
| `rotated` | Наклон листа 2–4 градуса | 3 | 1 |
| `low_res` | Низкое разрешение, мелкий шрифт | 3 | 1 |
| `smudges` | Пятна, шум, зачёркивания | 3 | 1 |
| `mixed` | Цифры, даты, римские цифры, имена, отрицания | 4 | 2 |
| `handwriting_font` | Печатный шрифт, имитирующий почерк (**не настоящая рукопись**) | 3 | 2 |
| **Итого** | | 24 | 10 |

**Разделение:** `dev` — для подбора параметров движка; `test` — отложенная выборка, добавленная после выбора параметров. Итоговые метрики считаются только по `test`. Разделение по текстам: одинаковых эталонных текстов в обеих выборках нет.

**Размечаемые сущности:** даты, имена, отрицания, термины — ошибки именно в них меняют смысл исторического ответа.

**Воспроизведение прогона:**

```bash
cd backend
uv run python -m app.services.ocr.evaluate --engine tesseract \
    --out ../docs/evaluation/ocr_evaluation.md
```

| CAT-03 | Корректное определение + неверный факт | 1 |
| CAT-04 | Факт повторяет определение | 1 |
| CAT-05 | Слишком общее определение при корректном факте | 1 |


## 3. Ограничения наборов

1. **Синтетика, а не реальные сканы.** Изображения отрисованы шрифтом и искажены фильтрами; реальная ручка, тетрадный лист, тени и перспектива дают другую статистику ошибок.
2. **Настоящая рукопись не измерена.** Tesseract не поддерживает русскую рукопись; категория `handwriting_font` лишь показывает, что стилизованные начертания распознаются хуже.
3. **Малый объём.** Отложенная OCR-выборка — 10 образцов (918 символов эталона); бенчмарк оценивания — 12 кейсов. Доверительные интервалы широкие; наборы подтверждают работоспособность логики и защитных механизмов, но **не репрезентативны** для реальных работ ЕГЭ.
4. **Генератор общий.** Тексты `test` написаны тем же автором и отрисованы теми же шрифтами, что и `dev`: это защищает от подгонки параметров, но не от смещения самого генератора.

Подробный разбор ограничений и постраничные ошибки — в [ocr_evaluation.md](ocr_evaluation.md) (§7) и [evaluation_quality_report.md](evaluation_quality_report.md) (§4).
