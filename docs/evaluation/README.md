# Оценка качества (Evaluation)

Документы о том, как измеряется качество OCR и оценивания, на каких данных и с какими ограничениями.

| Документ | Содержание |
|---|---|
| [evaluation_methodology.md](evaluation_methodology.md) | Методика оценивания: версионирование критериев, разделение инструкций, обработка неопределённости |
| [ocr_evaluation.md](ocr_evaluation.md) | Отчёт по качеству OCR: CER/WER, сохранность критичных сущностей, постраничный разбор ошибок, ограничения измерения |
| [evaluation_quality_report.md](evaluation_quality_report.md) | Отчёт по качеству оценивания на независимом бенчмарке из 12 синтетических кейсов |
| [test-dataset.md](test-dataset.md) | Описание синтетических тестовых наборов, команды воспроизведения, ограничения |
| [test-matrix.md](test-matrix.md) | Матрица соответствия требований и тестов (AC, сценарии A–J, FR-001…FR-052, NFR/SEC) |
| [qa-report.md](qa-report.md) | Итоговый QA-отчёт: результаты автотестов, сквозные сценарии A–J, реестр дефектов DEF-001…DEF-006 |

Ключевой принцип: метрики OCR и оценивания измеряются **раздельно**, на синтетических наборах; числа подтверждают работоспособность логики, а не точность на реальных работах ЕГЭ.
